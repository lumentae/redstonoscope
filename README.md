# Redstonoscope

A basic and easy to use Minecraft mod providing an oscilloscope to show the history of redstone values for 26.3.

## Installation
1. Download the mod and put it into your mods folder
2. Go into a single player world
3. Run `/redstonoscope location <x> <y> <z>`
4. The oscilloscope will appear in the top left corner

## Commands
`/redstonoscope toggle` - Toggles the UI

`/redstonoscope location <x> <y> <z>` - Sets the location to be probed for redstone values.

`/redstonoscope duration <ticks>` - Sets the duration shown in the oscilloscope panel.
